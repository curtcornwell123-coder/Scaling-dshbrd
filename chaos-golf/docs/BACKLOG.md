# Ultimate Golf: queued work (owner instructions)

Read this first when resuming. These are instructions from the game's owner, in priority order.

## Leaderboard balls (owner rule)
- Each leaderboard (Wins, Coins, Sabotages) has its **own exclusive ball**.
- A board's ball is **unlocked by finishing top 3 on that board's weekly leaderboard**.
- The podium on each board shows that board's own ball, so the three podiums always differ. The current bug is that all three show the leader's equipped skin, which in solo tests is the green Rookie ball on every podium.

## 1. Lobby: modern, sleek country-club interior, higher detail
- Indoor hub with a wood ceiling, **metal crossbeams**, **metal pillars**, marble floor with walnut inlays, leather lounges, warm pendant lights, and big windows onto the grass grounds. Centerpiece: a giant golf ball on a tee in a black stone pool.
- **Shorter overall**: lower ceilings in the hub and every room.
- No kid-style neon; signs in walnut and brass.
- Move **ball upgrades, locker and creator code out of the shop** into sleek stations with platforms at the hub edges, never in the middle.
- Keep things symmetric and centred. The spawn area was off-centre before; flank the spawn with matching totems (directory and group reward).

## 2. Shop: sleek, office-style layout
- Skins in clean rows instead of the ring of pedestals, much less floating-label clutter, tidy crate wall, and passes and coin packs along the side walls.

## 3. Leaderboard room: sleek redo
- Each board's own ball goes on its podium (see the rule above).

## 4. Practice range redo
- More spacious.
- Three permanent stations (Target, Long-Drive, Hazard), each with a distinct look, a **leaderboard per minigame**, and a **walk-up proximity hut** for that minigame's token shop. Huts are only for the minigame token shops.
- Show token balances on the HUD while in the practice area. Players couldn't see their Hazard tokens.

## 5. Rewards
- Playtime rewards plus a free playtime crate.
- Friends bonus that stacks per friend in the server. It currently exists only as a flat +15%.
- One-time group-only reward claimed in the main lobby (Corny Games group; read the group id from `game.CreatorId` once published).
